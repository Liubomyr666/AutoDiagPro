AutoDiag Pro iOS v1.3.1 — установка на реальный iPhone

Что уже подготовлено:
- Target: net8.0-ios
- Device RID: ios-arm64
- Release автоматически создаёт archive
- Bundle ID: com.autodiagpro.app
- iOS 15+
- Bluetooth LE / Wi-Fi OBD permissions
- Камера / фото
- AutoDiag AI и отдельные DTC-карточки

На Mac:
1. Установить Xcode и .NET 8 + MAUI workload.
2. Войти в Apple ID / Developer Team в Xcode.
3. Создать/выбрать provisioning profile для com.autodiagpro.app.
4. Открыть Terminal в этой папке.
5. chmod +x BUILD_IPA_ON_MAC.command
6. ./BUILD_IPA_ON_MAC.command
7. Готовая .ipa появится в bin/Release/net8.0-ios/ios-arm64/publish/

Для сборки с Windows:
- Нужен доступный по сети Mac с Xcode.
- Visual Studio/.NET использует Pair to Mac.
- Сертификат и provisioning profile должны существовать на Mac.

Важно:
Windows без Mac/Xcode не может финально собрать и подписать настоящий iOS .ipa.
