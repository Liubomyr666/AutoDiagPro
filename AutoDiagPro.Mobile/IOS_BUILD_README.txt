AutoDiag Pro iOS v2.0.0

Это мобильный клиент AutoDiag Pro с общей архитектурой Windows + AutoDiag Server.

Основные возможности:
- BLE / Wi-Fi OBD
- VIN, DTC, ECU info, Calibration ID, CVN, Readiness, Live Data
- Repair Brain, scan ДО/ПОСЛЕ, фото ДО/ПОСЛЕ
- AutoDiag AI и подбор деталей по VIN
- Автомобили, история, отчёты, сервисный план, износ
- СТО: work orders, CRM, запись, склад, QR-приём, счета, сотрудники/роли
- Programming Center с проверкой ECU/питания и capability check

Важно:
Стандартный ELM327/Vgate не является универсальным интерфейсом для ECU flash, coding, key programming или battery registration. Эти операции не имитируются: запись активируется только после реализации и проверки поддержанного марочного протокола и совместимого интерфейса.
