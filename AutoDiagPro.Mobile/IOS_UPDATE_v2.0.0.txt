AutoDiag Pro iOS v2.0.0 — ONE-SHOT UPDATE

ИНТЕРФЕЙС
- Единый стиль Windows/iOS: графитовый UI + янтарный AutoDiag Accent.
- 5 основных вкладок: Главная, Диагностика, Авто, СТО, Ещё.
- Оригинальные изображения Windows-клиента: hero_car, adapter, login_car и фирменный логотип.
- Нормальная мобильная навигация и отдельные страницы вместо десятков вкладок снизу.

OBD / ДИАГНОСТИКА
- Bluetooth LE и Wi-Fi ELM327/Vgate.
- VIN, протокол, напряжение, DTC.
- Полный scan с ECU info, readiness и расширенным Live Data.
- ECU / Calibration ID / CVN / ECU Name.
- Supported PID scanner.
- Readiness / MIL / количество сохранённых DTC.
- Live Data: RPM, ОЖ, скорость, нагрузка, STFT/LTFT, fuel pressure, MAP, timing, IAT, MAF, throttle, runtime, fuel level, distance since DTC clear, ECU voltage, ambient temp, oil temp, fuel rate.
- Безопасная очистка стандартных DTC с подтверждением и предупреждением о readiness.

REPAIR BRAIN
- Отдельные DTC-карточки.
- Локальная база типовых проверок и возможных деталей.
- AutoDiag AI: причины, срочность, порядок проверок, план ремонта.
- Scan ДО / ПОСЛЕ.
- Подтверждённая причина, выполненный ремонт, заметки.
- Фото ДО / ПОСЛЕ через камеру iPhone.
- Локальное сохранение repair case.

АВТО
- Vehicle Workspace.
- Добавление автомобиля прямо на AutoDiag Server.
- VIN / марка / модель / год / номер / пробег.
- История диагностики.
- Пробег / износ с честным разделением серверного пробега и доступных OBD-значений.
- Шины / колодки: фактические замеры и история.

ДЕТАЛИ / СКЛАД
- VIN Parts Finder через AutoDiag AI.
- Оригинал/аналоги, цены и поиск вариантов заказа.
- Запрет на выдумывание OEM-номеров без достаточных данных.
- QR/штрихкод через системный Apple Vision — камера или фото.
- Приём запчастей с привязкой к автомобилю.
- Локальный склад, группировка позиций и корректировка остатков.

СТО
- Реальные server work orders.
- Клиенты / CRM.
- Запись на сервис.
- Склад.
- Сотрудники / роли.
- Счета / чеки.
- Фото ремонта.
- QR-приём.
- Отчёты.

СЕРВИС
- Сервисный план.
- Текущий пробег, следующее ТО по км и дате.
- Масло / спецификация и список работ.
- Быстрые интервалы +10 000 / +15 000 км.

ОТЧЁТЫ
- Сканы AutoDiag Server.
- Заказ-наряды.
- Repair Brain cases.
- Service plan.
- Экспорт через системный Share Sheet iOS.

АДМИНИСТРИРОВАНИЕ
- Пользователи и роли с AutoDiag Server.
- Создание пользователя.
- Включение/отключение.
- Сброс временного пароля.
- Организации для Platform Admin.
- Включение/отключение организации.

PROGRAMMING CENTER
- ECU identification и проверка питания.
- Разделы: Programming ECU, Tuning/Stage, Coding/Adaptations, Keys/Immobilizer, Service ECU, Battery Coding.
- Подготовка профиля АКБ.
- AutoDiag не имитирует запись блока через обычный ELM327: реальные write/flash/coding/key операции доступны только после добавления поддержанного марочного протокола и совместимого интерфейса.
